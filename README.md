# 🚀 이것만 알면 준호처럼 할 수 있다!
### 초보 교사를 위한 안티그래비티(Antigravity) 에이전틱 코딩 & 웹앱 배포 연수 슬라이드

본 저장소는 코딩 경험이 전혀 없는 초·중·고 교사들을 대상으로 구글 **안티그래비티(Antigravity)**를 활용하여 교실 맞춤형 웹앱을 제작하고, GitHub & Netlify로 배포하는 과정을 인터랙티브하게 학습할 수 있도록 제작된 웹 기반 프레젠테이션 애플리케이션입니다.

---

## 🌟 주요 특징 및 차별점

1. **5인 멀티 에이전트 협업 체계 구현**
   - 단순 단일 챗봇이 아닌, **[👑총괄 PM / ✍️내용팀 / 🎨디자인팀 / 🔍검수팀 / 💡컨설턴트팀]**이 협업하여 만든 슬라이드 구성
   - 슬라이드 상단의 **[에이전트 인사이트]** 버튼을 통해 각 장표별 에이전트 제작 회의록 열람 가능
2. **실시간 인터랙티브 체험 도구 내장**
   - 🤖 **Gemini 챗봇 vs Antigravity 에이전트 비교 시뮬레이터** (Slide 5)
   - 🧠 **교육 도메인 지식 퀴즈 & 사고력 확장** (Slide 3)
   - 🛠️ **에러 발생 & AI 자동 복구 시뮬레이터** (Slide 10)
   - 📋 **골든 프롬프트 4단 조립기 & 원클릭 복사기** (Slide 11)
   - ⏱️ **실습 1: 3분 집중 타이머 라이브 위젯** (Slide 13)
   - ⚔️ **실습 2: 한국사 사진 퀴즈 배틀 라이브 위젯** (Slide 14)
   - 🪑 **실습 3: 스마트 학급 자리배치기 라이브 위젯** (Slide 15)
   - 🏆 **실습 4: 구글 시트 연동 실시간 랭킹전 라이브 위젯** (Slide 16)
   - 📱 **Netlify URL 실시간 QR코드 생성기 & 팡파레 축하 효과** (Slide 17)
3. **발표자 전용 모드 (Presenter Guide)**
   - 강사용 티칭 꿀팁, 교실 비유 가이드, 돌발 질문 대처 스크립트 수록 (단축키 `P`)
4. **교사용 비밀 서랍 & 고치기 모드**
   - 단축키 `T`로 실시간 교사용 팁 열람, `✎ 고치기 모드`로 화면 텍스트 즉시 수정 및 자동 저장
5. **무설치 단독 구동 & 반응형 웹**
   - 별도의 빌드 과정 없이 `index.html` 파일을 더블 클릭하여 브라우저에서 바로 실행

## ⌨️ 키보드 단축키 안내

| 키 | 기능 |
| :--- | :--- |
| `→` / `Space` / `PageDown` | 다음 슬라이드로 이동 |
| `←` / `PageUp` | 이전 슬라이드로 이동 |
| `Ctrl + P` | 전체 19개 슬라이드 고화질 PDF 인쇄 / 저장 |
| `A` | 5인 에이전트 회의록 서랍 열기/닫기 |
| `P` | 강사용 발표자 노트/꿀팁 모달 열기/닫기 |
| `T` / `ㅅ` | 교사용 비밀 서랍 열기/닫기 (닫기: `ESC`) |
| `M` / `ESC` | 전체 19개 슬라이드 목차 맵 열기/닫기 |
| `F` / `ㄹ` | 전체화면 모드 토글 |
| `Home` / `End` | 첫 번째 / 마지막 슬라이드로 즉시 이동 |

## 🌐 Netlify 1분 배포 방법 (웹 링크 만들기)

1. [Netlify(app.netlify.com)](https://app.netlify.com)에 로그인합니다.
2. **Sites** 탭에서 `안티그래비티 강의` 폴더를 화면에 그대로 **드래그 앤 드롭**합니다.
3. 5초 만에 생성된 `https://random-name.netlify.app` 주소를 확인하고, **Site settings > Change site name**에서 예쁜 주소(예: `junho-antigravity.netlify.app`)로 변경합니다.
4. 슬라이드 17번의 QR코드 생성기에 주소를 넣고 스마트폰으로 공유합니다!
