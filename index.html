왜 안티그래비티와 캔바를 연결할까요?

복잡한 그래픽 툴을 직접 만지지 않아도 "우리 학교 축제 포스터 제목 바꿔줘", "가정통신문 안내장 표지를 파란색 톤으로 맞춰줘"라고 말만 하면 안티그래비티가 캔바 디자인을 직접 열고 수정해 줍니다!

교사용 캔바 무료 계정 100% 호환
1단계

안티그래비티 MCP 설정창 열기

안티그래비티 화면 왼쪽 아래의 톱니바퀴 아이콘 (Settings) ➔ [MCP Servers] 메뉴를 클릭하거나, 설정 파일을 직접 엽니다.

📁 설정 파일 위치:
~/.gemini/antigravity/mcp_config.json
2단계 (핵심)

캔바 공식 MCP 원격 서버 코드 등록

설정 파일의 mcpServers 항목 안에 아래 캔바 원격 MCP 주소를 그대로 붙여넣습니다. (별도 설치 없이 npx로 1초 실행) 

{
  "mcpServers": {
    "canva": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://mcp.canva.com/mcp"
      ]
    }
  }
}
3단계

캔바 계정 1회 로그인 및 권한 승인

설정 저장 후 안티그래비티 대화창에서 캔바 작업을 요청하면, 웹 브라우저에 캔바 공식 로그인 및 연동 허용창이 자동으로 뜹니다.

✨ [승인(Allow)] 버튼을 한 번만 누르면 연동 끝! (복잡한 API 키 발급 전혀 불필요)
4단계

대화창에서 한국어로 지시하기

캔바 템플릿 링크를 대화창에 복사해 넣고 바꾸고 싶은 글자나 스타일을 한국어로 편안하게 말씀하세요.

💬 "이 캔바 템플릿(https://www.canva.com/...)에서 축제 날짜를 10월 25일로 고쳐줘"

선생님들이 가장 자주 묻는 질문 (FAQ)

Q. Node.js나 npx가 없다고 에러가 나면요? 포털 사이트에서 'Node.js'를 검색해 LTS 버전(무료)을 한 번만 설치해 주시면 바로 해결됩니다.
Q. 학교 컴퓨터 망이나 보안에 걸리지 않나요? 캔바의 공식 HTTPS 웹 표준 주소(https://mcp.canva.com/mcp)로 직접 통신하므로 학교 교내망에서도 안전하게 작동합니다.
