# 📊 구글 스프레드시트 실시간 랭킹전 1분 설정 가이드

본 가이드는 연수 강사 및 교사가 구글 스프레드시트를 **0원짜리 실시간 클라우드 데이터베이스**로 만들어, 수십 대의 스마트폰/노트북에서 제출된 점수를 실시간으로 연동 집계하는 방법을 설명합니다.

---

## ⚡ 1분 초간단 설정 순서

### 1단계: 구글 스프레드시트 만들기
1. [Google 스프레드시트(sheets.new)](https://sheets.new)에 접속하여 **새 스프레드시트**를 만듭니다.
2. 제목을 `[연수용] 학급 랭킹전 DB`와 같이 알아보기 쉽게 지정합니다.
   *(시트 헤더는 스크립트가 첫 실행 시 자동으로 만들어주므로 빈 화면 그대로 두셔도 됩니다)*

---

### 2단계: Apps Script 코드 붙여넣기
1. 상단 메뉴에서 **[확장 프로그램] > [Apps Script]**를 클릭합니다.
2. 화면에 기본으로 적혀있는 `function myFunction() { ... }` 코드를 **전부 지웁니다.**
3. `backend/google-apps-script.js` 파일의 **전체 코드**를 복사하여 붙여넣습니다.
4. 상단의 **[저장 💾]** 아이콘을 누릅니다.

---

### 3단계: 웹 앱(Web App)으로 배포하기 ★가장 중요★
1. 우측 상단의 파란색 **[배포]** 버튼을 누르고 **[새 배포]**를 선택합니다.
2. 좌측 톱니바퀴 아이콘을 눌러 **[웹 앱]**을 선택합니다.
3. 다음 3가지 설정을 정확히 확인합니다:
   * **설명**: `학급랭킹 API` (자유 입력)
   * **다음 사용자로 실행**: `나 (내 이메일)`
   * **액세스 권한이 있는 사용자**: **`모든 사용자 (Anyone)`**  👈 **반드시 선택!**
4. **[배포]** 버튼을 클릭합니다.
   *(처음 1회 구글 계정 [액세스 승인] 창이 뜨면: 계정 선택 ➔ [고급(Advanced)] 클릭 ➔ [제목 없는 프로젝트(으)로 이동] 클릭 ➔ [허용] 클릭)*
5. 배포 완료 창에 표시되는 **웹 앱 URL**을 복사합니다.
   * 주소 형태: `https://script.google.com/macros/s/AKfycbx.../exec`

---

### 4단계: 연수 슬라이드에 연결하기
1. 연수 프레젠테이션의 **16번 슬라이드(실습 4: 구글 시트 연동 랭킹전)**로 이동합니다.
2. 우측 데모 상단의 **[⚙️ 시트 설정]** 버튼을 클릭합니다.
3. 방금 복사한 **웹 앱 URL**을 붙여넣고 **[연결 및 저장]**을 누릅니다!
4. 상단 배지가 **`🟢 라이브 구글 시트 연결됨`**으로 바뀌면 준비 완료!

---

## 🎮 연수 시연 진행 팁 (강사용)

1. **사전 준비**: 16번 슬라이드에서 [⚙️ 시트 설정]으로 내 구글 시트 URL을 미리 등록해 둡니다. (브라우저에 자동 영구 저장됩니다)
2. **연수생 참여 유도**: 
   - 17번 슬라이드의 QR코드를 통해 교사들이 각자의 스마트폰/태블릿으로 슬라이드 16번에 접속하게 합니다.
   - *"선생님들, 16번 슬라이드로 오셔서 각자 성함이나 별명을 넣고 10초 연산 랭킹전에 참여해 보세요!"*라고 안내합니다.
3. **교탁 대형 화면 시연**:
   - 강사 화면에 참여 교사들의 이름과 점수가 실시간으로 계속 갱신되며 순위(Top 5)가 뒤바뀌는 모습을 교탁 화면으로 보여줍니다.
   - *"보시는 것처럼 서버나 유료 프로그램 없이, 선생님들이 쓰시는 구글 시트 하나만으로 전교생 실시간 웹앱이 이렇게 간단히 완성됩니다!"*라고 강조하며 실습으로 넘어갑니다.
